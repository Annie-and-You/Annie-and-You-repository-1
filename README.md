# 手势交互虚拟 DJ

一个计划使用笔记本内置摄像头，在浏览器本地追踪双手、操作虚拟 DJ 控件并播放本地音乐的项目。

## 当前状态

截至 2026-10-24，仓库处于**启动文档阶段**：已建立需求、架构、接口草案、协作规范和研究记录，尚未实现应用代码，也没有完成摄像头或音频实机验证。

目前没有 `package.json`、可运行网页或应用测试。下文描述的是已确定的目标与实施顺序，不是已交付功能。工程初始化后，再补充实际可用的安装、启动、测试和构建命令。

## 最终目标

- 使用笔记本内置摄像头，在网页摄像头画面中显示看起来放置在桌面上的虚拟 DJ 面板。
- 允许手动调整屏幕角度、摄像机位和面板四角，不要求自动识别、自动贴合或持续追踪桌面。
- **支持双手同时操作不同控件**：首先实现一只手调音量，另一只手调低通滤波，互不抢占。
- 从本地选择 MP3、常见 PCM WAV 等浏览器可解码的音频，通过手势播放、暂停和调节参数。
- 在两位开发者各自的笔记本上，使用桌面版 **Microsoft Edge** 完成约 10 分钟的实际体验验收。

“桌面投影”指摄像头画面中的虚拟叠加效果。项目不使用实体投影仪，物理桌面本身不会发出控件图像；也不要求识别真正的指尖触桌。

## 分步实现

| 阶段 | 交付内容 |
| --- | --- |
| 摄像头实验 | 预览、手部骨架、指尖、诊断数据；从一开始就检查未来双手所需的活动范围 |
| 单手交互实验 | 可移动、缩放的二维矩形面板，捏合按钮和推子 |
| 阶段 MVP | 本地单曲加载、播放／暂停、音量，单手可用 |
| 必做桌面阶段 | 四角手动透视校准、正确的反向命中映射、低通滤波 |
| 必做双手阶段 | 双手独立抓取不同控件，处理交叉、丢手和恢复，完成最终实机验收 |

**单手和二维矩形面板只是中间 MVP，不能作为整个项目完成的标准。** 双音轨混音、搓碟、自动对拍、丰富的 3D 场景与动画可继续扩展，不阻塞上述基础终态。

默认操作是食指定位、捏合抓取、移动拖动、松开释放。丢手时冻结对应控件，音乐保持当前状态；恢复后先松手，再重新抓取。鼠标与键盘保留用于首次启用、校准和后备控制。

## 技术方向与本地处理

计划采用 Vite、React、TypeScript、MediaPipe Tasks Vision、DOM/CSS、Canvas 2D 和 Web Audio API。桌面透视先用平面映射实现；有明确视觉需求后再引入 Three.js／React Three Fiber。当前单曲功能不依赖 Tone.js。

摄像头图像、手部识别和音乐处理均在本地完成。运行时不上传媒体、不申请麦克风；模型和 WASM 与应用资源一起本地提供。首次安装依赖、取得模型等开发准备仍可能需要联网。本地开发服务器用于提供网页资源，不是音乐上传服务器。

Edge 是正式验收目标，但目前尚未验证 MediaPipe 在两台实际电脑上的兼容性与性能。约 10° 的俯角只是待实验的候选机位，不是硬性要求或效果保证。
